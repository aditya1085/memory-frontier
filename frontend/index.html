Can a fixed-size memory remember a growing conversation?

THE ONE-SENTENCE CLAIM A fixed-size Hebbian synaptic memory can match KV-cache retrieval accuracy at small context sizes, but degrades through interference as more facts are written — while a KV cache stays accurate but grows without bound.

Transformers keep every past token's key and value around so they can look anything up later. Brain-inspired architectures like Pathway's Dragon Hatchling instead compress the past into a fixed-size synaptic state. This page lets you run both side by side, with real numbers, and try to break the claim above yourself.

03 · FORGETTING LAB

What decay λ actually controls

λ is the retention factor in W_t = λ·W_{t-1} + η·(v kᵀ). Higher λ keeps old synaptic strength around longer — but that also means old writes keep contributing to every later retrieval, which is exactly what causes interference. Move the slider; both effects update together.

Synaptic accuracy vs. sequence length at this λ

No hidden limit: at λ ≈ 1.0, nothing decays, so every past write keeps contributing to W at nearly full strength — this typically increases interference at large sequence lengths rather than fixing it, because more facts stay "loud" at once.

04 · CONNECTING TO DRAGON HATCHLING (BDH)

Where this idea shows up in BDH

This prototype isolates one mechanism from a real, published architecture. It is not a reimplementation of BDH and is not claimed to behave identically — the comparison below is deliberately explicit about what matches and what doesn't.

THIS PROTOTYPE

Hebbian fast-weight update

W_t = λ · W_(t-1) + η · (v kᵀ)
  • W — fixed (dim × dim) synaptic matrix, one per memory
  • λ — global decay applied uniformly every write
  • η — fixed learning rate
  • Retrieval: W @ query, no sparsity, no non-negativity constraint
DRAGON HATCHLING (BDH)

Synaptic memory via neuron-synapse formulation

  • Attention is reformulated as synaptic memory that updates as the model reads, via Hebbian-style writes between neuron-like units, not a single dense matrix update per step.
  • Activations are sparse and non-negative — roughly 5% of neurons active at a time in reported runs — unlike this prototype's dense real-valued matrix.
  • Connectivity is scale-free / heavy-tailed: a few units act as highly-connected hubs, rather than the uniform dense connectivity of a plain outer-product update.
  • BDH-CQ extends this so the model adapts from demonstrations without a written chain of thought and without updating weights at inference — adaptation lives entirely in this recurrent synaptic state.

What this prototype demonstrates about BDH's design pressure

The KV-cache vs. synaptic-memory trade-off shown in the Playground is the same trade-off BDH's architecture is built to manage: unbounded, exact recall (Transformer KV cache) vs. bounded, plastic state that can generalize to arbitrary sequence length but is vulnerable to interference. BDH's sparsity and monosemantic-synapse design are, per its published account, specifically aimed at reducing that interference compared to a naive dense Hebbian update like the one used here — which is precisely why this prototype's accuracy degrades faster than BDH's reported long-context results. That gap is the limitation this project is most honest about: we did not reproduce BDH's sparsity constraints, so this prototype's degradation curve should be read as an upper bound on the problem, not a measurement of BDH itself.

Limitations & scientifically safe claims

  • This is a simplified Hebbian/fast-weight prototype inspired by synaptic-plasticity ideas used in BDH. It is not a reimplementation of BDH and should not be treated as one.
  • The Recall Lab's free-text embedding is a deterministic hash-based toy embedding with no semantic understanding — it distinguishes strings, it does not understand language.
  • "Synaptic memory is O(1) in space" refers specifically to the memory matrix size with respect to sequence length, for a fixed memory dimension — not to compute cost or to every aspect of the system.
  • Degradation curves are measured on a controlled, uncorrelated associative-recall benchmark (random unit vectors). Real-world text has structure a language model can exploit; these numbers should not be read as a prediction of real-world model behavior.
  • All charts either call the live backend at run time or explicitly say "precomputed" when the backend is unreachable — see experiments/benchmark.py for the exact script used to generate any precomputed numbers.
